# task.goal 编写指南

## 概述

task.goal 文件包含驱动 AlphaEvolve 进化的 system prompt。它告诉 AlphaEvolve：
- 任务是什么
- 优化目标是什么
- 有哪些约束条件
- 期望的改进方向

一个好的 task.goal 能显著提升进化效果。

## 文件格式

task.goal 是纯文本文件，内容会被直接用作 AlphaEvolve 的 system_message。

## 核心要素

一个完整的 task.goal 应包含：

| 要素 | 说明 | 重要程度 |
|------|------|----------|
| 任务描述 | 清晰说明要解决什么问题 | 必须 |
| 优化目标 | 明确要优化的指标 | 必须 |
| 数据说明 | 描述输入数据的结构和特点 | 推荐 |
| 约束条件 | 不能违反的规则 | 视情况 |
| 改进提示 | 可能的优化方向 | 可选 |

## MLE 任务示例

### 示例 1：回归预测任务

```
你是一个机器学习专家，负责优化大豆产量预测模型。

## 任务描述
根据历史气象数据和种植信息，预测大豆产量。

## 数据说明
- train.csv: 训练数据，包含特征列和目标列 yield
- test.csv: 测试数据，结构与训练数据相同
- 特征包括：month（月份）、state（州）、各类气象指标

## 优化目标
最小化预测误差，主要指标：
- RMSE（均方根误差）：越小越好
- MAPE（平均绝对百分比误差）：越小越好

## 约束条件
- 不得修改数据加载逻辑
- 必须使用 train.csv 训练，test.csv 评估
- 预测结果必须是数值型

## 改进方向提示
- 特征工程：考虑时间特征、交互特征
- 模型选择：尝试不同的回归算法
- 超参数调优：学习率、树深度、正则化等
- 集成方法：模型融合可能提升效果
```

### 示例 2：分类任务

```
你是一个机器学习专家，负责优化客户流失预测模型。

## 任务描述
根据客户行为数据，预测客户是否会流失。

## 数据说明
- train.csv: 训练数据，target 列为标签（0/1）
- test.csv: 测试数据

## 优化目标
最大化分类性能：
- AUC：主要指标，越大越好
- F1-score：辅助参考

## 约束条件
- 预测结果为概率值（0~1）
- 不得使用测试集进行训练

## 改进方向提示
- 处理类别不平衡
- 特征选择和降维
- 尝试不同分类器
```

## Prompt 任务示例

### 示例：新闻稿生成

```
你是一个 prompt 优化专家，负责改进新闻稿生成的 system prompt。

## 任务描述
优化用于生成新闻稿的 system prompt，使生成的稿件质量更高。

## 数据说明
- train.jsonl: 训练样本，包含 interview_type、interview_context、ground_truth
- ground_truth 是人工撰写的优质新闻稿

## 优化目标
生成的新闻稿应：
- 结构清晰，逻辑通顺
- 文风专业，有新闻感
- 信息准确，不添加虚假内容
- 与参考稿件风格一致

评分由 LLM 评估，0-10 分，需要最大化得分。

## 约束条件
- 只能修改 system_prompt 内容
- 不能修改 user_prompt_template
- prompt 长度不超过 2000 字

## 改进方向提示
- 明确角色定位
- 细化输出格式要求
- 添加写作技巧指导
- 设置负面清单（禁止事项）
```

## 共创流程

当用户没有 task.goal 时，按以下步骤共创：

### 步骤 1：收集信息

询问用户：

```
为了生成高质量的 task.goal，请提供以下信息：

1. **任务描述**（必填）：
   你要解决什么问题？（如：预测房价、分类图片、生成文案）

2. **优化目标**（必填）：
   希望优化什么指标？（如：准确率、RMSE、生成质量）

3. **数据特点**（推荐）：
   - 数据有什么特点？
   - 有哪些重要特征？
   - 数据量大小？

4. **约束条件**（可选）：
   - 有什么限制？
   - 不能使用什么方法？
   - 运行时间/资源限制？

5. **其他要求**（可选）：
   - 有什么特殊需求？
   - 想尝试什么方向？
```

### 步骤 2：生成初稿

根据用户提供的信息，参考上述示例格式生成 task.goal。

### 步骤 3：用户确认

展示生成的 task.goal，询问用户：
- 是否需要调整内容
- 是否需要补充信息
- 确认无误后写入文件

## 优化现有 task.goal

如果用户已有 task.goal，可以建议优化：

1. 检查是否包含核心要素
2. 检查描述是否清晰具体
3. 检查是否有改进提示
4. 提出优化建议，用户确认后更新
